Cloudflare Web Analytics を開く ↗

💡 解析タグ（ビーコン）の有効化手順：

  1. Cloudflare ダッシュボードにログインし、「Web Analytics」を開きます。
  2. 「Webサイトを追加」でサイトURL（mod-portal.pages.dev など）を入力します。
  3. 発行された計測トークン（Token）をコピーします。
  4. サイトの各HTMLファイル末尾に自動でタグが挿入されるため、特別なサーバー管理なしですぐに計測が始まります。
